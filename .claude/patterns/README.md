# Pattern library

Durable, repo-specific patterns and conventions accumulate here — one Markdown
file per pattern (`<slug>.md`). They capture the non-obvious "how we do X in this
repo" knowledge that would otherwise be re-derived every session.

## Conventions

- One pattern per file; name it `<kebab-case-slug>.md`.
- Start each file with a one-line summary, then the pattern, then a short example.
- Patterns are added via the `/learn` skill (if available) or by hand.

## Keeping the table of contents fresh

The repo's [`CLAUDE.md`](../../CLAUDE.md) holds the **table of contents** for this
folder. Whenever you add, rename, or remove a pattern file here, update that ToC
in the same change so the index never drifts.
